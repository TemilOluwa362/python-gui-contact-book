# Python GUI Contact Book

## Files
1. `contactbook_gui.py`: the main app with the graphical interface
2. `contactbook.py`: the original version of the contact book

## Features
1. Adds new contacts.
2. Views saved contacts.
3. Names are automatically capitalized
4. Phone numbers are formatted with the +234 country code
5. Searches for contacts by name.
6. Deletes contacts and updates after.

## How to run
1. Install Python 3 from python.org
2. Download `contactbook_gui.py` from this repo
3. Run `python contactbook_gui.py`
